# Director Studio — 冰川版 V2 视觉验收规则（不是代码测试替代品）

设计基准：用户先前确认的《Director Studio 冰川版 V2》九页面综合图和分别细化的 `01_home.png`、`02_characters.png`、`03_scenes.png`、`04_props.png`、`05_storyboard.png`。遵循：每功能独立 URL，主工作区整体切换；原稿高保真色彩、布局和焦点优先，绝不是所有页面共用三栏后台表单。

## 本轮布局验收

| 页面 | 设计稿对照重点 | 真实功能限制 |
|---|---|---|
| 首页 | 玻璃事务所雪山横幅、四大快捷按钮、双列进度/任务卡，主屏不再叠加大段工程指标 | 进度必须基于已登记镜头及真实批准状态，不显示原图中虚构的 42% |
| 角色库 | 左角色列表、中主预览、右三视图、下方分类资产；详情与审核有层级 | 三视图只能来自 V2 角色资产；吉皮提正式母版未批准不得假展示 |
| 场景库 | 左侧双列卡片、右侧大图和场景信息标签；完整编辑留在弹窗 | 场景图如果尚未制作，显示真实空状态；无 S01～12 假图 |
| 道具库 | 左道具目录、中大图、侧边角度缩略图和版本操作 | 来源图需先保存，候选不等于正式母版 |
| 分镜图 | 31 镜头列表、中央画布、右镜头事实和底部时间线；编辑/上传/审核进入专用窗口 | 仅有真实已上传分镜图才能预览，不生成模拟剧照 |
| 视频制作 | 左制作单、中央预览、下方生产指令，明确执行器阻塞 | GPU 未接通时不显示假渲染进度或成片 |
| 制作任务 | 任务表格含负责人、优先级、状态，右侧任务详情 | 数据来自项目级任务表，不造假进度 |
| 项目设置 | 独立项目规格编辑与版本审核，避免空图片预览占位 | 已批准规格按真实项目/剧集保存 |

## 双轨质量门槛

**自动化：** `ci-studio.yml` 运行 JavaScript 语法检查、Python 回归与 Playwright Chromium 空状态页面截图。`studio/tests/visual_layout_smoke.py` 检查桌面端列顺序、页面互斥以及手机视口溢出。截图作为 GitHub Actions Artifact `studio-v2-browser-layout-shots` 保存 14 天。该报告只证明静态 CSS 布局，不能证明线上的私有数据或图片渲染正确。

**实际网页：** VPS 部署后，登录 Microsoft 所有者会话，分别在 1440×900 和手机视口检查：页面导航/前进返回、主页视觉、现有角色/场景/道具素材、31 镜头分镜切换、照片上传、版本审核、白模时间轴、制作单导出和任务表。截图与上述设计稿逐项人工比较。真实页面不一致时必须标记 **UI 验收未通过**，不得写“已经完全还原”。

## 安全及数据

所有媒体只允许同项目私有视觉来源，正式审核不能由纯 UI 状态替代。EP01 31 镜头、160 秒、7 张原有图应在升级前后保持不变。该迭代不启动 GPU，不修改 Hub，不转移微软账号。
