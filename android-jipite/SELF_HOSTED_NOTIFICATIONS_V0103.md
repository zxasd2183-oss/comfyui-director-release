# 吉皮提 V0.10.3：完全自建 VPS 提醒（无需小米开发者平台）

吉皮提正式签名的 **manual** 发行版从未依赖 Mi Push SDK、Google FCM 或小米开发者 AppID。本版本补充了自建提醒，而不是绕过小米系统权限。

## 自建架构

1. 已有的 VPS `/api/v1/mobile/pending` 是唯一数据源：每次请求都需要 Microsoft ID Token 和本机已绑定的 `device_id`。
2. **前台**：App 活跃时可选每约 45 秒以 HTTPS 检查待审批操作。找到新的、未过期的请求后，通过 Android `NotificationManager` 弹出本地通知。
3. **后台**：App 设置里用户主动启用后，由纯 Android `JobScheduler` 周期任务检查。最低请求间隔是 15 分钟；系统的 Doze、低电量、网络状况和小米 HyperOS 省电策略可能延迟甚至阻止执行。
4. 后台 Job 通过已有 MSAL 安全缓存尝试无交互获取短期 Microsoft ID Token；无法静默续期时停止，不弹出登录窗口，不缓存新令牌到明文偏好设置。
5. 只在授权的待审批查询返回新申请时发送泛化通知；不附带身份凭据、签名、配对码和设备 ID。
6. 点击系统通知只**打开吉皮提审批页**，没有任何“通知直接批准”操作。逐次 BIOMETRIC_STRONG 签名与 VPS 已绑定公钥验签仍然是必须条件。

此方案**不保证锁屏或被小米后台清理后秒级送达**；因此高风险 GPU 操作不能把通知准时送达作为安全/及时性的承诺。用户始终可手动进入审批页刷新。

## 使用方式

- 安装正式签名 V0.10.3，不需要申请小米开发者平台。
- 设置 → **自建 VPS 通知（不接小米平台）** → 开启「启用自己的 HTTPS 待审批提醒」。
- 安卓 13+ 系统若询问通知权限，请允许「吉皮提」。
- 小米系统中允许吉皮提接收通知；如果希望提高后台收到通知的机会，按系统实际菜单开启后台自启动，并把后台电池使用设为「无限制/不限制」。系统不同型号菜单可能不同；不要关闭系统整体安全保护。
- 关闭开关会取消 App 自己的后台周期任务，不影响 VPS 端和 Microsoft 登录。

## 与 v0.10.3 指纹自检的关系

本版本也新增「审批 → 安全审批链路自检」，用于确认 Microsoft 身份、VPS 绑定、公钥签名和防重放，不创建、不批准真实 GPU 操作。此功能需要**独立部署**新增的 VPS API，详见 `vps-control/JIPITE_BIOMETRIC_SELFTEST_V0103.md`。

## 隐私与限制

- 不新增任何第三方云推送账号、厂商 App Secret 或 Google Play Services 依赖。
- 不储存 OAuth 访问令牌到自建通知偏好；只储存是否启用和已通知请求集合的 SHA-256 摘要用于去重。
- App 收到的消息只依赖真正 Microsoft 验证和已绑定设备查询；恶意者不能通过推送系统直接批准。
- 本功能没有开启 GPU 电源写权限；原来的审批、一次性指纹签名和 `read_only` 模式不变。
