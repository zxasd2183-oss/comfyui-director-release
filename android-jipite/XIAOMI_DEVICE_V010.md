# 吉皮提 v0.10.0 · 小米真机安全绑定准备与验收

本阶段保留 v0.9.x 微软个人账号登录、Fluent 轻量界面、VPS HTTPS 更新和人工审批。没有开启 GPU 电源写权限；不强行添加未经审核的 Mi Push 依赖。

## v0.10.0 增加的真实安全门槛

1. 检测到常见 Android 模拟器（例如 MuMu、ranchu、goldfish、Genymotion）或 Debug 离线版本，禁止真实设备绑定与审批。这是**辅助判断而不是可信远程设备证明**。
2. 必须有安全锁屏和 Android `BIOMETRIC_STRONG`（通常是符合条件的指纹，某些人脸方案未必满足等级）。
3. 新建/使用 Android Keystore P-256 审批密钥时，检查 `KeyInfo` 的 TEE / StrongBox 安全等级、每次使用都要求认证、认证由安全硬件执行。若检查不通过，不能发送配对码，也不能签名审批；不自动重置密钥或 VPS 绑定。
4. 用户主动点击「绑定此手机」，先阅读**唯一设备绑定**确认，然后用 BiometricPrompt + Keystore CryptoObject 完成一次真正的本地硬件认证及签名。**只有成功后**才发送 Microsoft ID Token、受信任的公钥和本人的一次性配对码到 VPS。
5. App 不能绕过 VPS 端的唯一设备限制、身份验证、challenge 验签、过期与防重放检查。生物识别失败 / 取消 / 超时不会发出配对请求，也不会执行 GPU 操作。
6. 本地安全检测仅在用户查看安全诊断时读取状态，**不会为检测而创建签名密钥**。实际绑定会创建密钥并验证硬件安全级别；这是两个不同阶段。

## 真机上接下来如何验收

现有用户已经在 MuMu 完成了微软登录、VPS HTTPS 和版本更新测试；MuMu **不要输入真实配对码**。

1. 在自己可信的小米国行真机上安装同一签名的 v0.10.0 APK（可以先通过现有 VPS 下载渠道获取）。
2. 开启手机的锁屏密码和指纹；打开吉皮提，先完成 Microsoft 个人账号登录。
3. 进入「审批 → 首次设备绑定 → 检查本机强生物识别和硬件密钥」。确认没有模拟器警告，且安全锁屏和 BIOMETRIC_STRONG 已就绪。
4. 在本人**私有的 VPS SSH 终端**读取管理员保留的首次配对码，**只能输入手机 App，不向聊天、日志、截图、GitHub 或他人分享**。如果服务器已绑定其他设备，必须先由 VPS 管理员在 SSH 下经审计安全重置，不能由 APK 绕过。
5. 点击「绑定此手机」，认真阅读唯一设备绑定警示 → 继续生物识别。设备必须实际完成符合要求的指纹/强生物识别，然后才会向服务端发出绑定请求。
6. 绑定成功以后，刷新待审批申请应该显示“暂无申请”（没有申请是正常的）。不要为了测试而制造真实 GPU 开关机。可以先进行**只读查询**及本地安全检查。

## 报错与处理

- **模拟器或无生物识别**：用小米真机；不要在 MuMu 导入配对码。
- **安全硬件不足**：不会创建有效绑定；不要关闭证书检查，不要把软件密钥伪装成硬件密钥。
- **device_already_enrolled**：服务器已绑定另一设备或之前已有配对记录；用户本人在 VPS SSH 下审计和处理，不要反复尝试配对。
- **wrong_device / device_not_enrolled**：本地设备 ID 与服务端不匹配；不要删除应用数据，不要把配对码发给聊天。
- **biometric_signature_invalid**：拒绝操作；检查是否更换过指纹，必要时重新安全绑定。**绝不可自动批准或静默替换现有密钥**。
- **Microsoft 登录过期**：回首页点击「使用 Microsoft 账号登录 / 重新验证」，再刷新。
- **没有 Mi Push 通知**：国行推送仍需官方 SDK、应用资质及真机验证；现阶段在审批页手动刷新即可。推送消息永远只是提醒，不携带审批能力。

## 安全边界说明

- `KeyInfo` 由本机 Android 返回，属于**本地硬件安全检测**，不是 VPS 可验证的设备完整性/远程证书证明；运行环境被恶意篡改仍有残余风险。
- 每张真实批准申请仍必须经用户阅读信息、显式确认、逐次强生物识别签名和 VPS 防重放验签。
- VPS GPU 权限独立控制；本阶段不改变 TOTP 后备审批，也不让通知或配对请求自动执行 GPU 操作。
- **只有以后用户明确要求，且真机与 VPS 经过端到端验证，才能考虑更进一步的正式 GPU 操作启用。**

参考：Android KeyStore `KeyInfo.getSecurityLevel()`、`KeyInfo.isUserAuthenticationRequirementEnforcedBySecureHardware()` 和 `BiometricPrompt.CryptoObject`。
